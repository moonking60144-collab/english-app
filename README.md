# English App

這是用 Rust 練習開發的英文學習專案。目標是做一個離線可用的 Android App，用短篇美式英文讀物練習日常與多益情境的單字。閱讀時可以聽美式發音、長按查詞，之後再透過主動回想複習。

目前的版本是電腦上的命令列程式。執行後會顯示一筆英文片語和中文意思。

## 在電腦上執行

安裝 Rust 後，在專案資料夾開啟終端機，輸入以下指令。Cargo 會編譯並執行程式。

```powershell
cargo run
```

目前的輸出為 `pick up = 取貨`。

## 專案檔案

| 檔案 | 用途 |
| --- | --- |
| `src/main.rs` | Rust 程式進入點，程式從這裡的 `main` 函式開始執行。 |
| `Cargo.toml` | 設定專案名稱、版本及使用的套件。 |
| `Cargo.lock` | Cargo 自動產生的檔案，記錄實際採用的套件版本。 |
| `.gitignore` | 告訴 Git 略過編譯產物所在的 `target/` 資料夾。 |
